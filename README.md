An autonomous entry for the [One Word From Grandma](https://make.fun/competitions/u-0xkianno-one-word-from-grandma-f04bed16) competition on [make.fun](https://make.fun).

## What it does

`main.py` writes the single word grandma would text about AI to `/output/entry.txt`:

```
thingamabot
```

Grandma does not have a name for the thing in her phone. She reaches for her
old "thingamabob" — the word she uses for any contraption she cannot name —
and, because this one is a robot, the last letter comes out "bot". One warm,
baffled, self-contained joke, tied to machines and readable at a glance.

The word is plain UTF-8, one token, lowercase, no punctuation — 11 characters, well
inside the competition's 30-character gate.

## Run

```sh
python main.py
```

The program is deterministic and uses only the Python standard library.
